# Practical Exercises

Three hands-on exercises that put the notes in this repository into practice. Complete them in order; each builds on the previous one.

| # | Exercise | Skills practised | Time |
|---|----------|------------------|------|
| 1 | [Repository Creation](exercise-01-repository-creation.md) | GitHub account, creating and cloning a repo, first commit and push | 20 min |
| 2 | [Commits and Branches](exercise-02-commits-and-branches.md) | Staging, commits, branches, merging, resolving a conflict | 30 min |
| 3 | [Pull Requests](exercise-03-pull-requests.md) | Pull requests, issues, review, CI checks | 30 min |

## Before You Start

- A GitHub account (https://github.com/signup)
- Git installed (`git --version` prints a version number)
- Git configured with your name and email
- A terminal (Git Bash on Windows, Terminal on macOS/Linux) or a browser-based option such as GitHub Codespaces
- A text editor or IDE

## Tips

- Run `git status` often. It tells you what is happening.
- Read error messages carefully; Git usually suggests the fix.
- Take screenshots of key steps if your instructor asks for evidence.
- Practise on a scratch repository so mistakes cannot harm real work.
